## 1. 一句话

**本数字孪生在低速区（v ≤ 0.50 m/s）的结论有实测支撑；
超出该区间的外推结论不成立，且平台结构上无法在高速区稳定训练。**

---

## 2. 三条已实测的事实

### 2.1 优势包络（D0 扫描，11 格 × 3 策略 × 100 seed）

| 速度带 | 结论 |
|---|---|
| **v ≤ 0.50（训练带内）** | RL 全胜且优势巨大（0.53–2.79 obs-cm vs P+FF 2.09–4.81） |
| **v = 0.55（边界带）** | 优势收窄；最紧间距 `d=0.20` 处翻转为 P+FF 领先（差 0.086 true-cm，量级可忽略） |
| **v = 1.0（分布外）** | **五格全部反转**（RL 7.42–9.13 vs P+FF 3.30–6.21 obs-cm，差一个数量级） |

### 2.2 退化机制（为什么外推失效）

残差策略是 **regime-local**：PPO 学到的是低速小残差；
结构先验（`v_l + k·e`，V2V 速度广播）可外推，但在执行器摆率限制下
高速段**纠错权限收缩**——`v_cmd = clip(v_l + 0.8a, 0, 1.3)` 在 `v_l=1.0`
时最多提速 1.30×（`v_l=0.30` 时 3.67×）。

### 2.3 训练稳定性边界（v2/v3/probe 三次实测）

含高速段的训练**全部发散**（末 std 6.13 / 3.98 / 4.40，对照 v1 的 1.40 稳定）：

| 跑次 | band | 末 std |
|---|---|---|
| v1 | U(0.25,0.50) | 1.40 稳定 |
| v2 | U(0.25,1.00) | 6.13 发散 |
| v3 | U(0.25,1.00)窄课程 | 3.98 发散 |
| probe | **U(0.80,1.00) 窄带纯高速** | 4.40 发散 |

⇒ 唯有「stage2 是否含高速」区分稳定与发散；**窄带纯高速亦发散**。

## 3. 声明的适用范围

**可以声称**：
- v ≤ 0.50 m/s 的跟车精度优势（1.00 cm 名义 / 1.06 cm DR，零碰撞）；
- 跨车队间距规格的零样本适配（0.2/0.5/1.0 m，架构性泛化）；
- 混沌性的**诚实披露**：优势随速度衰减，1.0 m/s 处反转。

**不可声称**：
- 「RL 在全速度域优于手工规则」；
- 「孪生已验证 AGV 典型速度带（1.0–2.0 m/s）」——**上界 1.0 是 AGV 速度的下沿**，
  且平台在高速区**结构上无法稳定训练**（见 §2.3）；
- 任何基于 1.0 m/s 以上外推的性能论断。

## 5. 对 Phase D（硬件采购）的含义

- **正面**：若「速度自适应先验」成立，真车价值**上升**——真实执行器可标定真实速度带，
  而孪生在高速区不可信恰说明需要实物对照；
- **反面**：若高速区在本平台不可训，则 Sim2Real 的对照区间应**明确限定在 v ≤ 0.50**，
  采购论证不得引用高速区结论。
