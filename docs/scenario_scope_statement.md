# 可信包络与平台速度上界声明

> **状态**：定稿（owner 裁决 2026-09-22，H-D0.8 第三支落定后）。
> **来源**：`docs/scenario_audit.md`（D0 扫描实测）+ `RUNLOG.md` 2026-09-22 发散诊断与 H-D0.8。
> **用途**：论文 v3 / README / Phase D 采购论证的权威范围依据。

---

## 1. 一句话

**本数字孪生在低速区（v ≤ 0.50 m/s）的结论有实测支撑；
超出该区间的外推结论不成立，且平台结构上无法在高速区稳定训练。**

---

## 2. 已实测的事实

### 2.1 优势包络（D0 扫描，11 格 × 3 策略 × 100 seed）

| 速度带 | 结论 |
|---|---|
| **v ≤ 0.50（训练带内）** | RL 全胜且优势巨大（0.53–2.79 obs-cm vs P+FF 2.09–4.81） |
| **v = 0.55（边界带）** | 优势收窄；最紧间距 `d=0.20` 处翻转为 P+FF 领先（差 0.086 true-cm，量级可忽略） |
| **v = 1.0（分布外）** | **五格全部反转**（RL 6.85–7.97 vs P+FF 3.30–6.21 obs-cm，为边界带的数倍至近一个数量级） |

### 2.2 退化机制（**实测事实 + 待判假设，分开表述**）

**实测事实**：残差策略是 **regime-local**——PPO 学到的是低速小残差；
结构先验（`v_l + k·e`，V2V 速度广播）可外推。控制权限随速度收缩为
算术事实：`v_cmd = clip(v_l + 0.8a, 0, 1.3)` 在 `v_l=1.0` 时最多提速 **1.30×**
（`v_l=0.30` 时 3.67×）。

**待判假设**：把上述权限收缩认定为反转的**因果**，尚未被单独检验
（见 §4 的机制边界）。**论文 v3 中须区分二者，不得把算术事实写成因果结论。**

### 2.3 训练稳定性边界（**六次 stage2 实测，同 610 updates**）

| 跑次 | stage2 band | g_high | 末 std | 判定 |
|---|---|---|---|---|
| v1 | U(0.25,0.50) | — | **1.40** | **稳定** |
| v2 | U(0.25,1.00) | 1.0 | 6.13 | 发散 |
| v3 | U(0.25,1.00)（窄 stage1） | 1.0 | 3.98 | 发散 |
| probe | **U(0.80,1.00)（窄带纯高速）** | 1.0 | 4.40 | 发散 |
| armA | U(0.25,1.00) | 0.4 | 4.45 | 发散 |
| armB | U(0.25,1.00) | 1.6 | 5.17 | 发散 |

**规律（干净的实证陈述）**：

> **残差 RL 在速度阈值以上发生「突变式」失稳**——表现为策略 `std` 爆炸
> （非性能渐变），且**与频带宽度、课程设置、动作参数化方向均无关**；
> **唯有「stage2 是否含高速段」区分稳定与发散**（窄带纯高速亦发散）。

## 3. 声明的适用范围

**可以声称**：
- v ≤ 0.50 m/s 的跟车精度优势（1.00 cm 名义 / 1.06 cm DR，零碰撞）；
- 跨车队间距规格的零样本适配（0.2/0.5/1.0 m，架构性泛化）；
- 优势随速度衰减、1.0 m/s 处反转的**诚实披露**；
- §2.3 的**发散规律**（这是一条独立发现，不依赖包络结论）。

**不可声称**：
- 「RL 在全速度域优于手工规则」；
- 「孪生已验证 AGV 典型速度带（1.0–2.0 m/s）」——环境 `_leader_v` 硬截 **1.0 m/s**，
  即**上界恰是 AGV 速度的下沿**，且平台在高速区**结构上无法稳定训练**（§2.3）；
- 任何基于 1.0 m/s 以上外推的性能论断。

## 4. H-D0.8 结果与机制边界

动作重参数化两臂**均未收敛**（armA 4.45、armB 5.17；阈值 ≤2.0，对照 v1 的 1.40），
执行树落**第三支**。

**机制边界（**防过度结论**，重要）**：`_check_reachable.py` 实测 `v_cmd` 的**可达集**
`[max(0, v_l−0.8), min(1.3, v_l+0.8)]` **与增益无关**（由冻结文件内 `V_MAX`/`ACT_GAIN` 锁定）
⇒ **本实验从未检验「权限不足是根因」**。故：

- **被证伪**：「动作重参数化足以解决宽带发散」（更强的说法）；
- **未证实亦未证伪**：「权限不足是根因」——判它须改冻结文件 `V_MAX`/`ACT_GAIN`，
  代价为铁律 2 全套。**当前不做**（优先级已让位 Phase D/E）。

**论文 v3 future work 口径**：
> 残差 RL 在权限受限先验下的高速训练失稳，其因果归因（权限天花板 vs 尚未识别的
> 动力学因素）需平台 v2 才能判定；本文将其作为**已刻画的平台速度上界**如实报告。

## 5. Phase D 含义（owner 定稿）

真车实验的价值定位调整为**低速包络验证 + 平台标定回路**：

1. **在可信包络 v ≤ 0.50 内验证 sim→real 迁移**——真车实测退化 vs 鲁棒性曲线
   预测的对照点，**RQ4 的原始问题在此闭合**；
2. **真车作为孪生的标定工具**——实测执行器 τ/a_max 反哺数字孪生参数，
   缩小「不可信带」；
3. **叙事锚定仓储人机共存低速区**——该工况下紧密跟随正是核心需求；
   核实后的 ISO 3691-4 引用（含其 0.3 m/s 固定限速）**落在本平台验证包络之内**
   （见下方引用框），故为「精确命中」而非「叙事翻转」。

> ### 引用（已于 2026-09-24 核实，铁律 1）
>
> **原叙事中的「约 ≤ 0.5 m/s」有误，已更正。** 一次核实结论：
> **ISO 3691-4:2023**《Industrial trucks — Safety requirements and verification —
> Part 4: Driverless industrial trucks and their systems》（2020 首版 / 2023-06 更新，
> 覆盖 AGV/AMR，欧盟 CE 协调标准）要求车辆对人员实施**分区速度适应**：
> **警告场**检测到人员 → 减速；**防护场** → 安全停止；防护场尺寸随
> **车速与系统响应时间**缩放（`S = K×T + C`）。
> **标准语境中唯一的固定限速是 0.3 m/s**，且仅适用于**人员检测被静默的工况**
> （如装卸站对接）。
>
> **⇒ 本平台的低速验证包络（v ≤ 0.50 m/s）恰好覆盖安全敏感的低速工况带**，
> 其中 0.3 m/s 这一固定限速值**落在我们的训练区间（0.25–0.50）之内**。
> 具体场站限速仍属**风险评估**范畴，标准不设统一数字。
>
> **⚠ 术语提示**：本机制是「检测场触发的分级减速」，**标准术语不叫
> 「速度-分离监控」**（SSM 是协作机器人 ISO/TS 15066 的用语）。对外文本用机制描述，勿用术语名。
>
> **证据等级（诚实标注）**：标准名称 / 版本 / 覆盖范围 / 分区机制 = **一次源确认**；
> **0.3 m/s 这一数值来自二手技术解读（非原文直读），置信度「高但非第一手」**。
