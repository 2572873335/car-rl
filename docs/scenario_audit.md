## 0. 一句话结论

**RL 的精度优势在训练速度带（v ≤ 0.50）内成立且显著；到 v ≥ 0.55 优势消失，v = 1.0 时全面反转（P+FF 胜）。**
且**反转不止发生在分布外的 v=1.0**——预登记为「分布内」的 `(d=0.20, v=0.55)` 格上 RL 亦**微幅劣于** P+FF
（2.845 vs 2.673 obs-cm），**使 D0.4 按其预登记定义如实判未通过**（见 §3）。

⇒ **D0.4 按其预登记定义判未通过**。

## 4. 终止原因全审计（铁律 5）

| 观察 | 数据 |
|---|---|
| RL 全部 11 格 | **100% timeout**，**零碰撞、零 offtrack、零 lost** |
| P+FF 全部 11 格 | **100% timeout**，**零碰撞** |
| P（退化基线） | 多格 100% collision（0.20/0.30、0.50/0.30）；1.0 档 71/48 次撞车 |

⇒ **RL 与 P+FF 在全部格子上均零碰撞**；精度差异是纯跟踪品质差异，非安全性差异。

## 5. 机制与限制（诚实条款）

1. **D0.2 余量仅 0.027 obs-cm（~1.7σ）**，结构性贴线（review2 B1）；阈值**未放宽**。
2. **D0.2 是绝对门**：P+FF 亦满足（5.731 ≤ 8）⇒ **不得**读成「D0.2 证明 RL 在 AGV 速度够用」。
3. **v=1.0 只比训练已见瞬时速度（sinusoid 达 0.70 m/s）高 43%**，非突变；避免过度 OOD 叙事。
4. **lost 窗口随 d_des 漂移**（`MAX_GAP=2.0` 绝对值）：d=1.00 时「允许松 1 m」。本批无 lost 触发。
5. **gap 轴零样本泛化是架构性的**（相对误差 obs + V2V 速度先验），非「学会新任务」。
6. **D0.4 失效格的划界疑虑（单独记录，不改判）**：`(0.20, 0.55)` 的 **常数** v=0.55 略高于
   训练采样上界 0.50（预登记以 sinusoid **瞬时**速度 0.70 为据把 0.55 划为分布内）。
   该格差距 **0.172 obs-cm（0.086 true-cm）**——**统计上可分辨**（~12σ，SE 紧）但**实际量级可忽略**，
   与 v=1.0 的 1.4–4.1 obs-cm 反转**不同量级**。此点供 §8 regime-extension 与后续判定参考。
