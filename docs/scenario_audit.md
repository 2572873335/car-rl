## 0. 结论（三段式 headline，owner 定稿；v=0.55 的措辞按实测精确化，见下注）

> **RL 在训练速度带内（v ≤ 0.50）全胜且优势巨大；v = 0.55 为边界带，
> RL 的领先幅度全面收窄、并在最紧间距处翻转为 P+FF 领先；v = 1.0 处五格全部反转给 P+FF
> （差 1.1–4.1 obs-cm，为边界带的数倍至近一个数量级）。**

**「边界带」是本审计比「反转」更细的产出**：
- **v ≤ 0.50**：分布内，RL 全胜（官方分布内结论**划在此处**，保守、与预登记一致）；
- **v = 0.55**：**边界带**——RL 领先幅度**全面收窄**（对比 v=0.30：1.47→−0.17、2.99→2.02、1.58→0.96 obs-cm），
  并在**最紧间距 `d=0.20` 处翻转为 P+FF 领先**（差 **0.086 true-cm，量级可忽略**）；
  **`d=0.50`/`d=1.00` 处 RL 仍领先**（2.02 / 0.96 obs-cm）。⇒ **混合带，不单独成结论**；
- **v = 1.0**：分布外，**五格全部反转**，差距为边界带的**数倍至近一个数量级**。

> **对 owner 定稿措辞的一处精确化（铁律 1）**：owner 原话为「v=0.55 边界带**优势消失**」。
> 实测显示 v=0.55 处**并非全格优势消失**：`d=0.20` 翻转，但 `d=0.50`/`d=1.00` RL 仍领先
> （0.96–2.02 obs-cm，非可忽略量级）。故本表记为「**优势收窄 + 紧间距处翻转**」。
> **三段的结论结构、以及「官方分布内划在 v ≤ 0.50」的裁决均不变**——仅该格描述按数据校正。

**D0.4 的失守格（`(0.20, 0.55)`）依此归类为边界伪影**：
RL 2.845 vs P+FF 2.673，差 −0.172 obs-cm = **−0.086 true-cm**。
**「12.4σ 可分辨」源自 100 seed 把标准误压得极小——统计显著 ≠ 实际显著**，
这正是假设登记设数值带的用意。判据形式上**记录为未通过**（预注册纪律），
但**结论层面归入边界带**，不改变审计主结论。

### 3.1 D0.4 未通过 → 归入**边界带**（owner 裁决）

预登记「分布内 = v ≤ 0.55」下，`(d=0.20, v=0.55)` 格 **RL 2.845 > P+FF 2.673**，
⇒ **D0.4 按其预登记定义判未通过**（预注册纪律：**未回填式改判**）。

**owner 裁决（2026-09-22）—— 该格是边界伪影**：
- 差距 **−0.172 obs-cm = −0.086 true-cm**，量级可忽略；
- 「12.4σ」是 100 seed 压低标准误的产物：**统计显著 ≠ 实际显著**；
- 与 v=1.0 的反转（1.1–4.1 obs-cm）**为数倍至近一个数量级**，是**不同现象**。

⇒ **官方分布内结论划在 v ≤ 0.50**；**v = 0.55 归类为「边界带」**，

> 而非把失守格开除出分布内）。plan §2.3/§2.4 的原意是**禁止事后放宽**，

## 5. 机制与限制（诚实条款）

1. **D0.2 余量仅 0.027 obs-cm（~1.7σ）**，结构性贴线（review2 B1）；阈值**未放宽**。
2. **D0.2 是绝对门**：P+FF 亦满足（5.731 ≤ 8）⇒ **不得**读成「D0.2 证明 RL 在 AGV 速度够用」。
3. **v=1.0 只比训练已见瞬时速度（sinusoid 达 0.70 m/s）高 43%**，非突变；避免过度 OOD 叙事。
4. **lost 窗口随 d_des 漂移**（`MAX_GAP=2.0` 绝对值）：d=1.00 时「允许松 1 m」。本批无 lost 触发。
5. **gap 轴零样本泛化是架构性的**（相对误差 obs + V2V 速度先验），非「学会新任务」。
6. **D0.4 失效格的划界疑虑（单独记录，不改判）**：`(0.20, 0.55)` 的 **常数** v=0.55 略高于
   训练采样上界 0.50（预登记以 sinusoid **瞬时**速度 0.70 为据把 0.55 划为分布内）。
   该格差距 **0.172 obs-cm（0.086 true-cm）**——**统计上可分辨**（~12σ，SE 紧）但**实际量级可忽略**，
   与 v=1.0 的 1.1–4.1 obs-cm 反转**不同量级**。此点供 §8 regime-extension 与后续判定参考。
