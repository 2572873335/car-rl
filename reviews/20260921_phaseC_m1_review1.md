## 二、重要问题

### 1. §1.2 防泄漏边界：**论证失效**，但**结论可守**

**plan 的论证**（line 66–70）："窗口由横移定义，横移就是横向位置的变化，
故 `e_lat_other` 是物理事实而非内部状态。"

**该论证的两块基石现已被 R1 抽掉**：(a) 更正后的机制**不再是横移**，而是 `lane_target=1 ∧ lane=0`——
一个**逻辑状态**；(b) 因此"物理可观测 vs 内部状态"这条界线**不再自动成立**，
因为 M1.3 现在要策略推断的恰是一个**不进入观测的逻辑量**。

**更硬的问题（plan 未提及）**：`blocker_action()` 是 `(gap, delta)` 的**确定性函数**：

```python
if follower_behind and in_band:   # in_band = guard_lo < gap < guard_hi
    return inner                  # lane_target 置 1
```

而 `gap`、`delta` **都在 follower 自己的观测里**（slot0 `delta_self`）。
⇒ **策略无需"从物理表征推断窗口"，它可以直接把封堵者的换道命令算出来**：
`lane_target[1] = 1 ⟺ (delta<0 ∧ 0.08<gap<0.90)`。
封堵者是**反应式**控制器，其"策略"本身对 follower 是**可解析的**——
"独立发现"因此退化为"**学着复现一个已知确定性规则**"，与 F23 想主张的"读出对手的不可回头窗"**不是一回事**。

**结论**：`lane_other`/`e_lat_other` 作为**物理量**入观测，在"不泄漏内部计时器"这一狭义上**可以成立**；
但 plan 的**论证**（"必须从物理表征推断窗口"）**不成立**，且
**即使观测不含 `lane_target`，它也可能被解析反推**——
**"无特权信息"这一主张需要重写**：应改为
"观测集为物理量；但封堵者规则是公开的确定性函数，故'自主发现'只能限定为
'从零学出等价于已知规则的策略'，**不主张**发现了脚本未知的机制"。
（这一条同样削弱 §0 的研究问题与 §6 的"涌现"期待。）

### 2. M1.2 碰撞阈值 0.25 **偏紧且锚在单次噪声抽样上**

实测（我的 `_rev_final.py` F3，5 seed 集 ×30 局，与 W6 §3 逐位吻合）：

```
  seed0: coll = 23% / 17% / 17% / 13% / 7%   （均值 15%）
```
plan 取 **0.25 = "最差观测 23%"**。但 23% 是 **30 局的一次抽样**，其标准误 ≈ ±0.077。
把阈值钉在一次**噪声上界**上，会让**正例本身**频繁失败：

- 若正例真实碰撞率 ≈ 0.15（5 集均值）：P(单集观测 > 0.25) = **0.070**
- 若真实 ≈ 0.23（最差集）：P(单集观测 > 0.25) = **0.383**
- 3 集"逐集判定"下，真实 0.23 的正例**至少一集失败**的概率更高。

⇒ **0.25 不是"诚实反映任务性质"，是把一个 1 样本的 max 当了总体上界。**
建议：按 §6 自列预案**先补测反制 50 seed**，
取 **均值 + 2×SE**（当前约 0.15 ± 0.02 → 上限 ~0.19）或**分位数上界**，
并**在判据里写明它是上置信界而非观测 max**。
（M1.1 的 0.55 = 0.78×70% 方向合理，实测正例最差集 0.70 > 0.55，`P(单集失败)=0.040`，可接受。）

### 4. §6 的**更干净替代设计**（plan 未列）
