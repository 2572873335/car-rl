## 一、拦截级问题（Reject 依据，逐条带实测证据）

### R1（★ 最重要）阶段 A 的「测量口径替换」**测不了 gap 可扩展性**——测的是偏移假量

plan §2.1（line 53–56）：「阶段 A 仅在评估脚本里替换 d_des…测量口径，复用已训 checkpoint，测它能否在新间距/速度下工作」。
核心技术前提 = **不改 `D_DES` 常量、只改评估口径**，就能测「0.50/1.00 m 间距」。

**实测证伪**（我的 T0 段，10 seed，`follow_env.py` 的 `D_DES` 恒为 0.20，只把评估量改为 `|gap−声称d|`）：

```
[PhaseA-sim] RL  claim d=0.50 (D_DES still 0.20)   e|-gap_claim=  30.01cm  gap_final=19.9cm
[PhaseA-sim] RL  claim d=1.00 (D_DES still 0.20)   e|-gap_claim=  80.01cm  gap_final=19.9cm
[PhaseA-sim] P+FF claim d=0.50 (D_DES still 0.20)  e|-gap_claim=  29.89cm  gap_final=20.2cm
[PhaseA-sim] RL  claim d=0.20 (D_DES still 0.20)   e|-gap_claim=   0.46cm
```

**机制**：`follow_env.py` 的 `_obs()`（line 148–150）与 `step()`（line 171）里 `e = gap − D_DES`，`D_DES` 恒为 0.20。
策略被训成「把 `obs[0]=e/0.5` 拉到 0」，即逼 gap→0.20。评估口径改成「vs 0.50」只是把**常值偏移**量一遍：
策略稳态仍在 19.9cm，于是「误差」恒= 0.50−0.20 = **30cm**（或 0.80=80cm），与策略能力**毫无关系**。
且 **RL（30.01cm）与 P+FF（29.89cm）在此口径下无法区分**——阶段 A 连「RL 是否比基线好」都测不了。

**结论**：阶段 A 的 scan **不是测量，是无条件输出的常量**。它会把 D0.3 导向「零样本在 0.50/1.00 全失效」，
但那是**测量伪影**，不是真实的分布外失效。按此方案跑，D0.1 会因「30cm>2.5cm」**无条件判 RL 失败**——而这是错的。

### R2 A/B 划分的前提反了——gap 可扩展性**只能**靠改 `D_DES` 测，且**改完零样本直接就成立，根本不用重训**

plan 的省钱逻辑（line 51–59）：省钱的钥匙是「阶段 A 不碰 `D_DES`（不碰冻结文件）」。但：
- **正确测量必须改 `D_DES`**（R1 已证）；
- 改完 `D_DES` 后，**既有 checkpoint 零样本直接成立**——我实测（monkeypatch，等价于「冻结文件里把常量改成 0.50/1.00」）：

```
RL  d=0.50 v=as-trained   rep=0.80cm  tru=0.40cm  min_gap=22.3cm  coll=0 /10   ← 0.5m 直接成立
RL  d=1.00 v=as-trained   rep=0.89cm  tru=0.45cm  min_gap=22.3cm  coll=0 /10   ← 1.0m 直接成立
P+FF d=0.50 v=as-trained  rep=3.21cm  tru=1.61cm  min_gap=22.1cm  coll=0 /10
```

**为什么成立**：`_leader_v()` 的 V2V 先验 `v_cmd = v_l + 0.8a`（line 163），策略主力输出 `a≈0`（速度匹配）；
`obs[0]=e/0.5` 是**相对误差**，策略只学「把喂进来的 e 拉回 0」。把 `D_DES` 改成 0.50/1.00，
喂进来的 e 就相对 0.5/1.0，策略照样把它拉到 0 → **gap 轴是「全局平移 + 相对归零」，架构上天然泛化**，无需任何微调。

**结论**：阶段 A 想省的钱（避免重训）**本来就不用花**；但它选的技术路线（不改 `D_DES`）**恰恰让它什么都测不到**。
「省钱设计」整体是**错置**的：真正必要且便宜的动作（改 `D_DES`）正是它回避的那个；而它认为昂贵的重训
（阶段 B 全程铁律 2 仪式）在 gap 轴上是**可证明多余的**。铁律 2 要求「改冻结文件→重训」是对的保守条款，
但 plan 应**先做一个「改常量+只重评不重训」的作用域决策**，而不是默认整条铁律 2 仪式。

### R3 §3 验收阈值的**单位口径未定义**，且该歧义让 D0.2/D0.4 从「过」变「挂」——不可判

plan D0.1/D0.2/D0.4 只写「mean|e| ≤ 2.5cm / ≤5cm / 不劣」，**未声明单位口径**。
仓库所有既有数字（RL 1.00cm、P+FF 1.93cm）都是 **obs 仪器口径（×200×m）**。读者会按同口径读。
而 D0.2 在 **1.0 m/s @ d≥0.5** 的实测（30 seed，`_d0_review3`）：

```
RL d=0.50 v=1.0 constant   true=3.99cm  → obs口径(×2)=7.98cm    【>5cm 阈值】→ 挂
RL d=0.50 v=1.0 sinusoid   true=3.44cm  → obs=6.88cm            【>5cm】→ 挂
RL d=0.50 v=1.0 brake      true=3.52cm  → obs=7.04cm            【>5cm】→ 挂
```

- 若阈值按 obs 口径（项目惯例）→ **D0.2 在 1.0 m/s 必挂**；
- 若按真 cm（×100）→ D0.2 过（3~4cm<5cm），但**没写**，赌读者猜哪边。
**一个验收门靠「读者猜单位」定生死，不可判。** plan 从未跑过 1.0 m/s 这一档，却把一个悬在阈值上下沿的判据立为门。

同时 **D0.1 的「12.5% 相对」算错了**：2.5cm / 50cm = **5%**，不是 12.5%（12.5% 只有当分母是 0.20 基准时才成立，
与「0.5m 档的相对误差」维度不符）。D0.1「与 0.20 档同等相对精度」也是虚的：0.20 档真实达到 RL 0.31 真 cm（1.5%@20cm），
D0.1 的 2.5cm@0.5m=5% 真相对，**比 0.20 档松 3 倍**——不是「同等」。

### R4 D0.4「RL 不劣于 P+FF」在 AGV 相关格子上**必然反转**，plan 未预见也未入风险表

实测（30 seed，obs 口径 = 真cm×2）：

| 格子 | RL obs-cm | P+FF obs-cm | RL 胜? |
|---|---|---|---|
| **d=0.50 v=1.0 constant** | 7.98 | 5.74 | **负**（RL 劣） |
| **d=0.50 v=1.0 sinusoid** | 6.88 | 5.74 | **负** |
| **d=0.50 v=1.0 brake** | 7.04 | 5.50 | **负** |
| d=0.20 v=0.30（as-trained） | 0.62 | 1.93 | 胜（与论文 1.00 vs 1.93 一致） |
| d=0.20 v=1.0 constant | 7.48 | 3.07 | **负** |

**结论**：RL「2× 优于手调规则」的头条，在**恰是 AGV 叙事相关的那一格（1.0 m/s）反转成 RL 劣于 P+FF**。
机制：高速下 `a_max` 摆率饱和（`car_following_sim.py:107` 的 slew-clip），PPO 学的是低速小残差，跟不上；
P+FF 直接 `v_l + kp·e` 大步修正，反而顶得住。**D0.4 要求「所有可物理成立的格子上 RL 不劣于 P+FF」→ 在高速格必挂。**
plan §5 风险表**没有这一条**（只写了「速度达不到」，实证却相反——1.0 m/s 稳定到达，max|e_lat|~8cm≪25cm off-track）。
这**不是 plan 的失败**而是审计该暴露的真相，但 plan 既不预见、不登记、也不说明「D0.4 挂了编排图该怎么画压力值」。

### R5 D0.3 与 D0.4 自相矛盾，且 D0.3 有滑向「不能输判据」的 Phase C 老路风险

- **矛盾**：D0.3（line 84）「零样本失效**不判负**，定义阶段 B 范围」；D0.4（line 85）「在**所有可物理成立的格子**上 RL 不劣于 P+FF」。
  高速冗余格在训练分布（`v_set~U(0.25,0.50)`，`follow_env.py:115`）之外，**正是「分布外」**——D0.3 说这些格不判负，
  D0.4 却要在「所有」格上判 RL 不劣。同格子**两套胜负**。必须明确**分布内格 vs 分布外格的判据归属**，否则可被挑着用。
- **D0.3 滥用风险**：若「哪个格输了就把它标成『分布外失效』」，则 **D0 无格可败**，审计=「怎么都不算失败」。
  这正是 Phase C「判据无法被违反」的覆辙（DATA_MANAGEMENT §10.7 拦截记录所列因果）。**补救**：D0.3 必须**先验地**把
  「阶段 B 范围」=「至少 N 个 AGV 相关格（如 0.50×0.55、0.50×1.00、1.00×1.00）必须**输出正值证据**（≤阈值且零碰撞）才算审计产出，
  并给出每个失效格的**量化重训成本上限**」；且**进 ASSUMPTIONS.md 预登记**，不许跑完再划范围。

## 二、重要问题 / 建议

### I1 刹车距离公式——**是对的**（但 plan 的推论「20cm/1.0 必撞」**经实测为假**）

`Car.step`（`car_following_sim.py:107`）的速度通道是**摆率限幅** `v += clip(v_cmd−v, −a_max·dt, a_max·dt)`，
**没有 τ**（τ 只在 omega，line 108）。因此**不是一阶滞后，刹车距离就是 v²/2a**。实测：

```
a_max=1.5 v0=1.00 -> 实测 0.3234m vs v²/2a=0.3333m   (DT 离散差)
a_max=1.0 v0=1.00 -> 实测 0.4900m vs 0.5000m
```
plan §2.3 的数值正确。但 **「1.0×0.20 = 物理必撞，跑它浪费」的推论错了**（21-seed/30-seed 实测）：

```
RL  d=0.20 v=1.0 constant  coll=0 /10（min_gap 19.4cm，有安全裕量）
P+FF d=0.20 v=1.0 constant coll=0 /10
RL  d=0.20 v=1.0 brake     coll=6 /10   ← 唯一危险：领头刹车 + 20cm
P+FF d=0.20 v=1.0 brake    coll=0 /10   ← 规则反而活
```
原因：`v_cmd=v_l+0.8a` 先验在**恒速/匀速**时 a≈0 即匹配，gap 根本不用收；只有领头**刹车瞬态**才需要跟随刹停，
而刹停所需并非「自身 1.0m/s 的 0.33m」，是**相对减速**。故 plan 的静态「刹距＞gap ⇒ 必撞」框架**过度简化**。
**推论**：不要剪掉 1.0×0.20——那里藏着真正的 RL 能力缺口（P+FF 能活、RL 撞 6/10），正是包络图最该亮的点；
「高速必配大间距」对 AGV 现实是对的，但**理由不是物理必撞**，而是「刹车瞬态下的鲁棒性」。

### I2 §2.1 矩阵 9 格不剪枝反而合理（与确认点 3 相反方向建议）

因 I1，1.0×0.20 并非「必撞浪费」，而是**承载 RL vs P+FF 关键对比**的格。建议保留 9 格；若要省算力，
可只对**恒速**档减 seed，把 ≥20 seed 留给 brake 行为的高速格。矩阵「d_des×v_set 两维」没问题（line 40–43），
确认点 3 里「三维」是笔误。

### I3 plan 声称「D_DES 进入 obs/奖励/**终止**」——终止**不依赖** D_DES（line 185–189 用绝对 gap 0.12 / 2.0）

`terminated` 用 `COLLISION_GAP=0.12` 和 `MAX_GAP=2.0`（绝对值），与 `D_DES` 无关。plan line 51 把终止算进 `D_DES` 影响面
是**事实错误**。后果：在大间距（d=1.0）下，“lost” 阈值 2.0m 离设定点 1.0m 很远，等效「允许松 1m」——
终止窗口随 d_des 漂移，审计表应对此说明。

### I4 §4 审计表分层（真实映射/缩放后成立/仅测试场）需**防自我服务式标注**

建议绑定证据门槛，谁写谁负责、独立复核签字：
- **真实映射**：需有**实物/行业来源**（标准条款号、厂商规格）或 D0 实测数字，不靠推理；
- **缩放后成立**：需**两张图**（某格实测包络 + 缩放论点），不得只写一句"可缩放";
- **仅测试场**：必须写「不可外推：<一句理由>」。
且 3 个标签的**预判版**要在跑 scan **之前**写进 `docs/scenario_audit.md` 草稿并交独立评审，**跑完只能收紧不能放宽**。

### I5 A1 去中心化（确认点 4）——叙事资产可进标题级，但须诚实标注「主张非实测」

`v_cmd=v_l+0.8a`（line 163）本质是**领车广播速度 + 车端残差决策**，确实是"车端决策 + V2V 分享"，
可作为 vs FMS 集中调度的差异化卖点进 README；但「车队规模上升时集中调度必成瓶颈」是**论证性主张、无实测/无引用**，
写标题级时必须加限定词，且 ISO 3691-4 等数字须标注条款与不确定度（确认点 6：**必须**请行业视角复核，或至少
把「0.5–2m 间距」标为设计指导范围而非硬标准——这是全文 M1/阈值设定的立足点，不能自说自话）。

### I6 §2.2 铁律 5「五类终止原因全报」——scan 里应含 `max|e_lat|` 与 `min gap`

高速实测 `max|e_lat|~8–9cm`（≪25cm），说明 1.0 m/s 在 follow_env 的 r=0.30 外圈**不碰曲率限速**（w_max·R=8×0.3=2.4m/s >1.0）。
plan §5「1.0 m/s 在弯道超曲率限速、速度达不到」**经实测为假**（能稳定达 1.0 且不出轨）——该风险行要么删，要么改写为
「高速刹停瞬态」（真实风险，见 I1）。

## 三、对待评审确认点 6 问的逐条答复

1. **阶段 A/B 划分是否恰当？** 不恰当。阶段 A 的「只换测量口径」**技术上测不了正确量**（R1）；且 gap 轴的可扩展性
   **必须改 `D_DES` 才测得着，而改完零样本直接成立**（R2，0.4cm）。正确做法：**阶段 A 应改为「改 `D_DES` + 复用现有
   checkpoint 重评（不重训）」**，铁律 2 走「作用域决策」而非默认全程重训仪式。速度轴（0.55/1.00）才是真 OOD，才是
   阶段 B 重训的正主。
2. **12.5% / 5cm 有没有依据？** 依据是编的——12.5% 算错（应为 5%）、「同等相对精度」对不上（0.20 档真实 1.5%）、
   且**未定义单位口径**（R3）导致 D0.2 沿 obs 口径在 1.0 m/s 必挂。阈值须**重定**：先定口径（建议沿用 obs 口径与全站一致），
   用已测的 0.3/0.55/1.0 全距实测反推一个**能区分方法、又留有余量**的档。
3. **矩阵应否按物理耦合剪枝？** **不**。1.0×0.20 并非必撞（I1），且是 RL-vs-P+FF 关键对比所在；高速配大间距是对的方向，
   但理由应改为「刹车瞬态鲁棒性」，不是「物理必撞」。
4. **A1 进标题级还是正文？** 可进标题级，但加限定词（I5）。它是唯一真正差异化卖点，值得前置；须诚实标注「论证主张」。
5. **D0.3 会被滥用吗？** 会——现写法=「怎么都不算失败」（R5）。必须加「≥N 个 AGV 相关格输出正值 + 每失效格量化重训成本上限 +
   预登记、跑后只收紧」。并与 D0.4 划清「分布内/外格的判据归属」，消除自相矛盾。
6. **审计表要行业复核吗？** 必须。间距 0.5–2m、去中心化优势、速度 1.0–2.0m/s 全部是**未标来源的领域断言**，却支撑 M1/M3/A1
   全部叙事与 D0 阈值。至少：给 ISO 3691-4/AGV 厂商/部署案例各一个可核引源 + 不确定度，并请 ≥1 位仓储/物流 AGV 从业者
   过一遍 `docs/scenario_audit.md` 的「真实映射/缩放后成立」标注——否则分层表仍是自说自话。

## 四、plan 未提及、我自行挖掘的问题

1. **RL 在 AGV 相关高速格反转劣于 P+FF（R4）**——这是 D0 跑出来最可能砸场的结果，plan 的风险表与展望**完全没有**这号未来。
   若真在 1.0 m/s 反转，整条「RL×仓储 AGV」叙事要改口（"RL 在低速鲁棒、高速需调/重训"），应提前想好措辞与 6.2 的恐惧屏障解释是否够。
2. **`_leader_v()` 的 BRAKE 行为在 v_set=1.0 时只降到 0.3 m/s**（`_leader_v` line 98 乘 0.3，clip 下限 0.05）——
   高速档的「刹车」是 1.0→0.3 的大瞬变，这正是 RL 崩溃点；扫描应把 brake 档**单独加高 seed**，否则高速结论不稳。
3. **初始 gap 与 d_des 的匹配**：`reset` 的 `gap0~U(0.20, gap_max=1.2)`（line 132）。在 d=1.0 下若 gap0 抽到 0.25，
   跟随者**起点超前设定点**、需主动松到 1.0——实测能处理（min_gap 正常），但 `gap_max=1.2` 是训练课程的紧上限，
   审计表应对「d=1.0 的初始条件合法性」显式说明，避免被质疑 watchdog。
4. **`max|e_lat|` 与 `min gap` 未列入 §2.2 指标**——高速格子的横向达 8–9cm、min_gap 达 18–19cm，这是「安全裕量」的关键证据，
   缺了它包络图的「零碰撞」没有守备深度。
