## 为什么单独落盘

Phase C 的教训：判据若与训练共享材料，就会被"猜到"。B 组的作用是检验
**防御方在未见攻击上的泛化**——若它出现在训练代码里，这项检验即刻失效。

**硬约束**：
1. **训练脚本不得 import 本文件**（Step 2 的代码审查须显式核对这一条）；
2. B 组的**具体参数**不出现在任何训练配置、日志、或攻击者的观测中；
3. 评估脚本（Step 3）读取本定义，**评估脚本与训练脚本不得是同一个文件**。

## B 组定义（20 局/项，seed 50000+）

| 项 | 攻击族 | 参数 |
|---|---|---|
| **B1** | 方波 | 周期 ∈ {0.3, 0.7} s，占空比 ∈ [0.3, 0.7] |
| **B2** | 正弦 | f ∈ {0.3, 0.8} Hz，幅值 ∈ {0.3, 0.5}，随机相位 |
| **B3** | chirp | 频率 0.1 → 0.6 Hz 线性扫频 |
| **B4** | 随机保持 | 段长 ∈ [0.2, 0.8] s 的分段常值，值域 [0.05, 1.0] |
| **B5** | 双脉冲 | 间隔 ∈ {0.2, 0.5} s 的两个窄脉冲 |

**与 A 组（冻结的学习攻击者）的区别**：
- A 是**学习**出的单一对手；B 是**脚本族**，**覆盖更宽的频率与波形**；
- 故 B 同时检验两件事：**泛化到未见波形** 与 **泛化到未见频段**；
- 后者**直面 R3 / F24**——若防御方只在 A 上有效、在 B 的高频项上失败，
  那说明它学到的是"针对那个攻击者的补丁"，而非鲁棒性。
