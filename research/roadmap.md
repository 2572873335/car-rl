## 2. 阶段计划

### Phase A：论文 v2 实验冲刺（9.20 – 10.3，两周）

**目标**：补齐三个"零成本高价值"实验，产出论文 v2 素材。

**W1（9.20–9.26）：鲁棒性曲线 + SAC 消融**

| 任务 | 细节 | 验收 |
|---|---|---|
| A1 鲁棒性扫描脚本 | 在 `follow_env` 增加扰动幅度参数（或外层包装 env），τ/a_max 偏离名义值 0/10/20/30/40/50%，每档评估 10 seed | `results/20260926_robustness_sweep/` 含曲线图 + 表 |
| A2 鲁棒性曲线图 | 横轴扰动幅度，纵轴 mean\|e\| 与成功率，两条曲线（RL vs P+FF） | 可直接入论文 5.4 节替换"开/关"表述 |
| A3 SAC 跟车对比【可选，可砍】 | SB3 `SAC` 同观测同接口训 2M 步，与 PPO/P+FF 同表对比；重点记录速度平滑性（高频残差 std）。**对主线叙事是加分项而非必需——两周节奏紧张时优先保 A1/A2/A4/A5/A6** | 表：PPO / SAC / P+FF 三列 |

**W2（9.27–10.3）：RQ2 离线 RL 对比**

| 任务 | 细节 | 验收 |
|---|---|---|
| A4 IQL/CQL 实验 | **d3rlpy**（`pip install d3rlpy`，自带 IQL/CQL/BCQ/TD3+BC；注意 sb3-contrib **不含**任何离线 RL 算法，勿用），输入 = 现有 4.2 万 BC 演示数据（`npz` 导出观测-动作对，d3rlpy 的 MDPDataset 格式），不与环境交互纯离线训练 | 评估：成功率/间距误差 |
| A5 三方对比表 | BC（已有 2/10）/ IQL / PPO 微调（已有 10/10）同种子评估 | 论文新章节"4.8 离线 RL 对比"素材 |
| A6 论文 v2 更新 | 摘要、5.2/5.4 节、新增 4.8 节、局限更新。**前置：确定作者署名与单位**（project_paper.md 现为"（你的名字）"占位，arXiv 上传必须有真实作者信息） | arXiv 上传，更新 `report/v2.0` tag |

**决策门 G1（10.3）**：A5 若出现"IQL ≥ PPO"或"BC 数据利用率惊人"等反直觉结果 →
不急着解释，先复跑三种子确认，确认后这是论文级发现，扩展成独立章节。

**风险与对策**：SAC 在 20s 长回合上收敛慢 → 降到 10M 预算并记录；IQL 需要数据
`npz` 导出格式 → 一天内可完成，写 `export_demos.py` 入库。

### Phase C：RQ3 自博弈（10.18 – 11.21，五周，含探针门）

**目标**：领头车从脚本升级为学习对手，回答 RQ3。

**W5（10.18–10.20）：3 天探针（硬门）**

- 任务：`PettingZoo.ParallelEnv` 封装最小双 agent 环境（两车，共享策略参数）+
  `MARLlib`（或 RLlib）跑通 MAPPO 官方示例级别训练 100k 步；
- **通过标准**：3 天内 loss 正常下降、出现非平凡行为（哪怕只是"不再撞墙"）；
- **失败预案**：立即放弃 RQ3，Phase D 提前两周启动，RQ3 降级为
  "脚本对手 + 行为随机化"（低对抗版本）写进展望。

**W6–W9（10.21–11.21）：self-play 主实验**

| 周 | 任务 | 验收 |
|---|---|---|
| W6 | 环境完整化：零和奖励（超车+1/被超-1）+ 混合模式（70% 任务 + 30% 对抗）；观测加入对手意图 | 健康检查通过（规则基线在新环境行为合理） |
| W7 | 假设登记（**先于训练写下**）：预期出现封堵行为、t_ot 分布变化、Elo 爬升；开始 self-play 训练 | 登记表入 research/ASSUMPTIONS.md |
| W8 | 训练 + 周期性快照对战评估（Elo 简易实现：胜率转分） | Elo 曲线 |
| W9 | 行为分析：视频/轨迹图找 2 个以上涌现策略；论文 v3 素材 | 报告新章节初稿 |

**风险与对策**：MAPPO 不收敛（MARL 常态）→ 先降难度（固定前车=旧脚本策略，
只训后车）；信用分配问题 → 换独立 PPO + 参数共享的最简实现，不上注意力。
