# Archived: W6 criterion reviewer's evidence scripts

**Status: archived for provenance. Not part of the pipeline.**

These are the independent reviewer's scripts from the W6 criterion review
(`reviews/20260921_phaseC_w6_review1.md` and `..._criterion_review2.md`).
Those reviews cite them by name as the basis for their findings, so they are
kept here to make the reviews verifiable from the repository.

Project rule (AGENT_HANDOFF section 5b): any file referenced by a commit,
document or erratum must have a home in the repo -- /tmp may never be its only
location. These were /tmp-only until this archive was created.

They were written to falsify the author's claims; several failed to reproduce
what the author had reported, which is how the errors were found.
